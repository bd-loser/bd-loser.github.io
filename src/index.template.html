opencode for Termux — a native Android AI coding agent

Run the open-source opencode terminal coding agent natively on your Android phone: a self-hosted alternative to cloud coding agents, rebuilt for Bionic aarch64 — no proot, no chroot, no root, no glibc.

1One command to install

Pick a channel, paste the command inside Termux. Afterwards pkg upgrade opencode keeps you current on that channel.

curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/repo-setup.sh | bash
curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/repo-setup.sh | OPENCODE_CHANNEL=beta bash
curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/repo-setup.sh | OPENCODE_CHANNEL=dev bash

stable tracks upstream release tags · beta and dev track the 2.x rolling lines (beta recommended for v2) · signed repository, one package: opencode.

2What's inside

Native, not emulated

Bionic aarch64 build — links Android's own libc directly. No proot, no chroot, no VM, no root.

Real terminal UI

The TUI runs on opentui, rebuilt for Android as the @androidtui packages — rendered on-device, 16 KiB page aligned.

Terminal sessions that work

Interactive PTYs via a Bionic-rebuilt bun-pty and a static-Bionic persistent pty service — real shell sessions, real tmux-style workflows.

Signed apt repository

Three channels (stable / beta / dev) in a GPG-signed repo. One build per upstream version, auto-synced from upstream about hourly.

Powered by patched Bun

bun-termux is Bun rebuilt for Bionic: SELinux-safe JIT, syscall traps, shebang remapping — the engine the agent runs on.

MIT, free, private

Same MIT license as upstream opencode. Nothing collected, nothing phoned home, everything open.

5How it works & FAQ

  • A patched Bun (bun-termux) links Bionic instead of glibc.
  • opentui is rebuilt for android-arm64 and published as the @androidtui packages.
  • An hourly watcher mirrors upstream opencode; each upstream version produces one signed .deb per channel.
What device do I need?

Any aarch64 Android phone on Android 10 or newer — essentially all devices from the last seven years. Only Termux is required; no root.

How do updates arrive?

pkg upgrade opencode on your chosen channel. Stable tracks upstream release tags; beta and dev track upstream's rolling branches, one release per upstream version, typically within the hour.

Is anything collected?

No. No analytics, no cookies, no third-party runtime requests on this site, and no telemetry in the packages. Sync state is anonymous.

What is bun-termux for?

It's the patched Bun runtime the agent itself runs on — and a general Bun for Termux if you want to build your own tools. Install with the command above.
